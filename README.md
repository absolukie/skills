# skills

Luke's public skill collection. Reusable playbooks for getting work done with AI agents.

## Skills

- **ab-toggle** — Single-button A/B toggle for comparisons: one switch, every tap flips. Sliding thumb shows the active side, stage crossfades between versions.
- **audio-redact** — Bleep PII (names, phone numbers, company names) out of audio recordings. Word-level timestamps find spoken phrases, ffmpeg bleeps them, re-transcription verifies.
- **autonomous-deep-work** — Autonomous deep-work mode for large, open-ended tasks: research, build, test, iterate with parallel agents while Luke is away.
- **before-after-slider** — Before/after comparison slider for photos and edits: drag a divider 1:1 with the finger, tap anywhere to glide there.
- **blog-decision-doc** — For each blog post, pre-vet the draft against Luke's checklist and build a tappable decision doc where he makes the final calls: title pick, his take, ship/revise/kill.
- **carousel** — One-card-at-a-time snap carousel: swipeable track, circular arrow buttons, per-slide N/total counter, optional filter chips, zero layout shift.
- **cloudflare** — Manage Luke's Cloudflare account via the API: deploy Workers, check deploy status.
- **decision-board** — Tappable decision boards: checkboxes, option pickers, autosaved notes fields instead of a doc or a wall of chat text.
- **design-system** — Build a design system before building the UI: presets, tokens, type scale, styled primitives, then something unique on top.
- **dr** — Run a Design Review: walk through any piece of work piece by piece, asking Luke about every part. Builds a tappable review board where he makes the final calls.
- **explainer-tools** — The family of explainer UI tools: reusable interactive patterns for explainer sites and posts.
- **github** — Work with GitHub via the API.
- **mastery-sheet** — Build a "mastery sheet": an interactive single-page visualizer that takes someone from zero to fluent on one topic.
- **morph-button** — A button that performs its primary action, then smoothly morphs into the natural next-step action (copy → share, download → open, send → track).
- **motion-design** — Motion design system for explainer films and animated web pieces: story-arc timing bands, motion language, scene specs, copy/sound/accessibility rules.
- **problem-finder** — Find business-worthy problems and vet them BEFORE pitching. Check first, pitch only survivors.
- **production-readiness** — Pre-launch production readiness review (PRR): the aggregated go-live checklist covering legal traps, billing, reliability, and UX.
- **retro** — End-of-session retrospective: scan for inefficiencies, mistakes, and learnings; convert each into an environment change so it can't recur.
- **security-review** — Pre-publish legal and security risk audit for apps: run before any App Store / Google Play submission or before marking a project verified.
- **seo** — Source material for a future SEO skill (currently collecting posts).
- **step-through-animator** — Step-through animator for explainers: walk an algorithm one operation at a time with a Next button that never moves between presses.
- **swipe-cards** — Tinder-style swipeable card deck for triaging a list, keep vs skip, one card at a time.
- **ui-recording-timeline** — Turn a screen recording of a UI into an interactive paint timeline: what painted when, and how long each screen was shown.
- **visualizers** — The five visualizer patterns: zoom bars, dot-grid simulator, live formula slider, estimator + caveat card, and source link-out cards. Dependency-free vanilla JS/CSS, mobile-first.

## Format

Each skill lives in its own folder with a `SKILL.md` describing its trigger phrases, workflow, output contract, and operating rules.
