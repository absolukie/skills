# skills

Luke's public skill collection. Reusable playbooks for getting work done.

## Skills

- **dr** — Run a Design Review (DR): walk through any piece of work (a blog post, a website, a design, a plan, anything needing a decision) piece by piece, asking about every part. Builds a tappable review board where Luke makes the final calls.

## Format

Each skill lives in its own folder with a `SKILL.md` describing its trigger phrases, workflow, output contract, and operating rules.
